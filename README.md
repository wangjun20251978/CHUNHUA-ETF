# 🌸 春华秋实 · ETF四季分批战法（国内版）

把「种花 → 浇灌 → 摘果 → 休耕」套进 ETF —— 教人**分批买、分批卖，别一把梭**。

👉 在线看板：<https://wangjun20251978.github.io/CHUNHUA-ETF/>

## 特点

- **只做国内**：A股宽基/行业 + 港股通共 **43 支**，已剔除纳指、标普500、德国、法国、日经等 5 只境外 ETF
- **四季战法**：春·播种 → 夏·浇灌 → 秋·摘果 → 冬·休耕，纪律化分批
- **每日自动更新**：每个交易日收盘后自动抓行情重算档位（GitHub Actions）
- **本地买断**：付费版是单文件 HTML，双击即用、不联网

## 三因子口径（公开可复核）

| 因子 | 口径 |
|---|---|
| M 动量 | 近 20 个交易日收益率(%) |
| V 估值 | 250 日价格区间位置分位 `(close-min)/(max-min)×100`，越低越便宜 |
| F 风控 | 收盘价 > MA60 **且** MA20 > MA60 → 通过（趋势向上） |
| 综合分 | `0.4×M分 + 0.3×V分 + 0.3×F分`，M分 = clamp(50+M×2.5, 0, 100)，V分 = 100−V，F分 = 100/0 |

## 四季归类规则

| 条件 | 季节 | 操作 |
|---|---|---|
| 风控 ❌ | ❄️ 冬 | 休耕（空仓观望） |
| 风控 ✅ 且 估值分位 < 50% | 🌱 春 | 播种（小仓试探） |
| 风控 ✅ 且 50% ≤ 估值分位 < 90% | 🍎 秋 | 摘果·高估值（分批卖） |
| 风控 ✅ 且 估值分位 ≥ 90% | 🍎 秋 | 摘果·极高（分批卖，别追） |
